# Фотографии

Положите сюда свои фотографии со следующими именами (или поменяйте пути в `js/config.js`):

- `photo-hero.jpg` — главный экран (жених и невеста)
- `photo-invitation.jpg` — блок приглашения
- `photo-guests.jpg` — блок «Құрметті қонақтар»
- `photo-hosts.jpg` — блок «Той иелері»
- `photo-couple.jpg` — переходное фото (руки, кольца, пара)
- `photo-datetime.jpg` — блок с датой и местом

Рекомендации: вертикальные фото (портрет), не менее 1200×1600 px, формат JPG.
Пока файлов нет — вместо фото показывается декоративная оливково-золотая
заглушка, сайт при этом не ломается.
